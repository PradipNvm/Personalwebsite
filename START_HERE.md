## ⚡ 5-MINUTE QUICK START

### Step 1: Open Your Portfolio (1 min)

**Option A - Windows (Easiest)**
```bash
# Open Command Prompt and run:
cd "d:\Portfolio website\Personal-portfolio"
python -m http.server 8000
```
Then visit: `http://localhost:8000` in your browser

**Option B - Direct**
- Double-click `index.html` to open in browser

**Option C - VS Code**
- Open `index.html`
- Right-click → "Open with Live Server"

✅ You should see your portfolio loading!

---

### Step 2: Update Your Name (1 min)

Edit `index.html` (Line 167):

**Find:**
```html
<h2>Pradip Pokhrel.</h2>
```

**Replace with:**
```html
<h2>Your Name.</h2>
```

**Refresh your browser** (F5) to see changes!

---

### Step 3: Update Your Tagline (1 min)

Edit `index.html` (Line 168):

**Find:**
```html
<h3>I bring imagination to life in 3D.</h3>
```

**Replace with:**
```html
<h3>Your amazing tagline here.</h3>
```

---

### Step 4: Add Your Photo (1 min)

1. **Save** your photo as `profile.jpg` (any size, square preferred)
2. **Place** it in the `assets` folder
3. Done! ✅ (It automatically appears in About section)

*Don't have a photo?* Leave the placeholder - site still works!

---

### Step 5: Update Your Email (1 min)

**Find these lines and replace email:**
- Line 142 (Side bar)
- Line 527 (Contact button)

Change: `Pradippokhrel96@gmail.com` → `your-email@gmail.com`

## 🚀 Next: Deploy to the Web

### Choose One Platform:

**1. Netlify (Recommended)**
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop your project folder
3. Your site is live! (gets a URL like `xxx.netlify.app`)

**2. Vercel**
1. Go to [vercel.com](https://vercel.com)
2. Import your project folder
3. Deploy! (gets a URL)

**3. GitHub Pages (Free)**
1. Push to GitHub
2. Enable Pages in settings
3. Live on `yourusername.github.io`

## 🐛 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Page won't load | Try double-clicking `index.html` |
| Changes don't show | Refresh browser (F5 or Ctrl+R) |
| Photo doesn't show | Check file is in `assets` folder |
| Links don't work | Check email format: `mailto:your@email.com` |
| Looks broken on phone | That's normal! Test with F12 toggle |
